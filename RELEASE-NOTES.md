# 一起玩牌 1.0.0 / Card Games 1.0.0

## 中文

- 在 AI 酱里与已配置的 AI 角色玩斗地主和无限注德州积分桌。筹码与好感结算由宿主管理，筹码不具有现金价值。
- 支持暂停和继续、局间补筹、手间调整德州座位、桌聊和德州手牌回放。斗地主新增发牌动画与结算前亮牌步骤，支持减少动态效果。
- 需要 AI 酱 2.0.4 及其 `voice-games-v1` 宿主能力。通过官方扩展目录安装时，需确认牌桌、模型、桌聊和复盘四项权限。
- 游戏规则和合成模型流程已有测试证据。真实模型牌力尚未验证，模型请求由用户已配置的连接处理。
- 源码公开，项目许可与素材来源见 [LICENSE.md](LICENSE.md) 和 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## English

- Play Dou Dizhu and no-limit Texas Hold’em points tables with your configured AI Buddy characters. AI Buddy handles settlement and affinity, and chips have no cash value.
- Pause and resume games, top up between rounds, change Hold’em seating between hands, use table chat, and replay completed Hold’em hands. Dou Dizhu adds a dealing animation and a hand reveal before the results screen, with reduced-motion support.
- Requires AI Buddy 2.0.4 and its `voice-games-v1` host feature. Installation from the official extension catalog requests four permissions for tables, models, chat, and replay.
- Rules and synthetic model flows have test evidence. Live-model playing strength has not been verified. Model calls use the connections you configure.
- Source code will be published. See [LICENSE.md](LICENSE.md) and [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) for the project license and asset attribution.
